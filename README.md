# NoExcusesClub Bot 💪

Telegram-бот для учёта ежедневных тренировок, поддержания спортивной дисциплины и проведения ежемесячных соревнований внутри сообщества.

## 🚀 Возможности

### Учёт тренировок

- Автоматическое начисление **1 очка** за отправленный в группу видеокружок.
- Ручная регистрация тренировки командой `/done`.
- Защита от повторного начисления очков за один день.
- Возможность отменить собственную отметку командой `/undo`.

### Рейтинг и статистика

- `/stats` — текущий рейтинг участников за месяц.
- `/mystats` — личная статистика тренировок.
- `/mytitles` — история личных чемпионских титулов.

Личные команды `/mystats` и `/mytitles` доступны в личном чате с ботом.

### Ежемесячные соревнования

- Автоматическое подведение итогов каждого месяца.
- Поддержка нескольких победителей при равенстве очков.
- Сохранение результатов соревнований в базе данных SQLite.
- `/winners` — история победителей прошлых месяцев.
- Сохранение личных чемпионских титулов участников.

### Автоматические отчёты

- Еженедельный отчёт каждое воскресенье в 20:00.
- Ежемесячное подведение итогов первого числа в 00:05.
- Все запланированные задачи используют настроенный часовой пояс.

## 🤖 Команды бота

| Команда           | Описание                             |
| ----------------- | ------------------------------------ |
| `/start`          | Запустить бота                       |
| `/done`           | Засчитать тренировку за сегодня      |
| `/done yesterday` | Засчитать тренировку за вчера        |
| `/undo`           | Отменить отметку за сегодня          |
| `/undo yesterday` | Отменить отметку за вчера            |
| `/stats`          | Посмотреть текущий месячный рейтинг  |
| `/winners`        | Посмотреть историю победителей       |
| `/mystats`        | Посмотреть личную статистику         |
| `/mytitles`       | Посмотреть личные чемпионские титулы |

## ⚙️ Правила клуба

- За одну тренировку начисляется 1 очко.
- Один участник может получить не более 1 очка за день.
- Видеокружок автоматически засчитывается как тренировка.
- Для ручной регистрации используется команда `/done`.
- Команда `/undo` позволяет удалить только собственную отметку.
- Ручная регистрация и отмена доступны за сегодня и вчера.
- Нельзя зарегистрировать или отменить тренировку за предыдущий месяц.
- Победителем месяца становится участник с наибольшим количеством очков.
- Если несколько участников набрали одинаковое максимальное количество очков, все они становятся победителями.

## 💻 Установка и запуск

### 1. Клонирование проекта

```bash
git clone YOUR_REPOSITORY_URL
cd NoExcusesClubBot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

В корневой папке проекта необходимо создать файл `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
CHAT_ID=your_telegram_group_id
TZ=Europe/Moscow
WEEKLY_REPORT_TIME=20:00
MONTH_RESULT_TIME=00:05
```

**Важно:** файл `.env` содержит секретные данные. Его нельзя публиковать в GitHub или передавать третьим лицам.

### 5. Запуск бота

```bash
python main.py
```

## 🗄️ База данных

Для хранения информации используется SQLite.

База данных содержит:

- Информацию об участниках клуба.
- Ежедневные отметки о тренировках.
- Результаты ежемесячных соревнований.
- Личные чемпионские титулы.
- Историю отправленных автоматических отчётов.

При запуске бота база данных и необходимые таблицы создаются автоматически.

## ☁️ Развёртывание

Проект рассчитан на постоянную работу на сервере или облачном хостинге.

Для развёртывания на Amvera или другой платформе необходимо:

- Настроить переменные окружения.
- Обеспечить постоянное хранение базы данных.
- При использовании постоянного хранилища Amvera настроить путь к базе данных `/data`.
- Убедиться, что приложение постоянно запущено.
